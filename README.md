# llm-wiki.si

Static landing page for **Donna — Living knowledge for AI agents**, served by GitHub Pages at <https://llm-wiki.si>.

- `index.html` — single self-contained page (CSS + JS inline, Google Fonts only external dependency)
- `assets/` — illustrations and the demo-story screenshots (`assets/story/`, WebP)
- `CNAME` — custom domain for GitHub Pages

This repository is the only source of the page: edit `index.html` here, commit, and push to publish.
