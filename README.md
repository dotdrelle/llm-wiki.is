# llm-wiki.is

Static landing page for **Donna — Living knowledge for AI agents**, served by GitHub Pages at <https://llm-wiki.is>.

- `index.html` — single self-contained page (CSS + JS inline, Google Fonts only external dependency)
- `assets/` — illustrations and the demo-story screenshots (`assets/story/`, WebP)
- `CNAME` — custom domain for GitHub Pages

Source of truth for the page: `llm-wiki/_tmp/branding/www` in the wikiLLM workspace.
